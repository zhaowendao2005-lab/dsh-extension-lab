# 文件工作台（Workspace IDE）

DSH 里的「小号 VS Code」，住在**右侧栏**里：一个宿主 tab，内部是文件/搜索左栏 + 可拖动分栏的标签工作区 + 真 PTY 终端。它只做三件事——**源代码管理（含提交图谱）+ 高性能文件查看编辑 + 真终端**，不掺任何模型对话。

## 入口

右栏开始页的「工作台」卡片。工作台按会话存在：每个会话一个 tab、一个根目录（该会话手动选择的目录 > 会话 `cwd` > 上次根目录），对话与工作台同时在场、互不遮挡。

## 快捷键

插件**不绑任何默认键**：11 条命令（`workspace-ide.explorer/search/scm/graph/panel/quickOpen/save/saveAll/nav/closeTab/fullview`）都以 `defaults: {}` 注册，全部功能都有面板内入口。要键位请进 DSH 设置页的「工作台」分区（左侧栏底部「设置」或账号菜单 → 工作台）：那里直接列出这 11 条命令，点「设置 / 修改」按下组合键即录制，可随时清除或恢复默认，不需要跳去宿主的公共快捷键面板。键位由宿主快捷键配置保存（Web 端 `localStorage['dsh.keybindings.v1']`），插件只做行内编辑；工具栏与右键菜单的按键提示仍从宿主 catalog 动态读取。

## 内部标签与分栏

- 工作区顶部是内部标签行：文件、差异、提交图谱、当前改动、仓库、命令都是标签；`×` / 中键 / 右键菜单（关闭当前、关闭其他、关闭所有）可关闭。
- 把标签拖到内容区的左/右/上/下边缘即可分栏（最多 4 组）；拖到中心是移动；分隔条可拖比例，双击复位；组内标签清空后自动合并。
- 左右分栏受最小宽度 180px 限制；右栏太窄时对应方向置灰并提示，不会把编辑器压坏。
- 「改动」默认按真实路径形成目录树，分「更改 / 已暂存」两组；目录可折叠、单链压缩，可右键切换列表。文件类型图标与 Git 状态独立，行悬停或聚焦即可打开、暂存 / 取消暂存；目录动作仅操作该目录的实际变更路径，列表窗口化。
- 工具栏「全视图」把工作台移入占 frame 80% 的对话框（关闭右栏 tab，内部标签保留），点外部/Esc/按钮关闭；需要键盘开关请在 DSH 设置页「工作台」分区给 `workspace-ide.fullview` 设置组合键。

## 视图与标签

### 文件 / 搜索（左栏）

- 工作区文件树，懒加载、虚拟滚动，万级目录不卡。
- 单击选中、双击打开；行内新建/重命名/删除/刷新；右键菜单。
- 打开即编辑：语法高亮、查找替换、折叠、多标签、脏标记、`Cmd/Ctrl+S` 保存。
- 大文件按 Host 文件模式与编辑器装配限制降级；超限只读并提示。自动换行独立受 2000 行 / 最长 500 字符限制，详情见 `docs/editor.md`。
- 全局搜索（优先自带 ripgrep，缺失时降级纯 JS），结果按文件分组、点击跳行。

### 仓库与命令（标签）

- 「仓库」扫描工作区内的 Git 仓库，以真实相对路径显示层级；默认不跟踪任何仓库。勾选后可设为活动仓库，只有活动仓库驱动改动、图谱与监听。跟踪列表与活动选择按工作区路径保存在本浏览器。
- 「命令」只有两个树根：`package.json` 与 `Scripts`。前者保留包文件真实目录层级，选择一个包后，后者显示其脚本名称、命令预览与播放按钮。
- 每次播放都新建终端，在该包目录使用系统默认 shell 和正常用户 profile 运行所选脚本；输出保留在这个独立终端，不复用正在执行其他命令的终端。
- 整体缩放、编辑器字号与快捷键都在 DSH 设置页的「工作台」分区（左侧栏底部「设置」或账号菜单 → 工作台）。缩放框可手填 50–200 的整数百分比（可带 `%`），非法输入就地提示且不覆盖已存值；编辑器字号 10–20px 是独立偏好；快捷键在该分区内录制、清除或恢复默认。
- 命令树按 VS Code 探索器风格排版：22px 行高、无逐行边框与分隔线、按真实目录缩进、悬停行高亮；播放按钮在悬停或键盘聚焦时出现（触屏常显）。文件树、SCM 与命令包节点共用 `FileIcon`，对包清单、锁文件、Git 配置、构建配置等特殊文件名使用专用内联图标。

### 当前改动（标签）

- 变更四组：**已暂存 / 未暂存 / 未跟踪 / 冲突**，同一文件可同时在两组（与 git 真实语义一致）。
- 逐文件：看 diff、暂存、取消暂存、丢弃（需确认）；目录和分组支持精确范围暂存 / 取消暂存。
- DSH 设置页「工作台」里的字号、Tab 显示宽度、缩进空格数和自动换行立即应用到编辑器与差异视图；不改写已有空格，超出换行阈值会显示原因。
- 提交框：多行、`Cmd/Ctrl+Enter` 提交、空消息禁用；P1 支持 hunk/行级暂存与 amend。
- 分支：显示当前分支、上游、ahead/behind，一键切换；不干净时拒绝并提示 stash。
- 刷新：操作后立即刷新 + 面板可见时轮询 + 窗口聚焦刷新；超大仓库自动降级为手动刷新。

### 提交图谱（标签）

- SourceGit 风格多泳道图，固定行高虚拟滚动，5 万条提交可流畅滚动（布局在 Host 计算，客户端只画可视区间）。
- 每行：泳道连线 + 提交圆点 + refs 徽章（HEAD/branch/remote/tag）+ subject + 短 hash + 作者 + 相对时间。
- 点选看提交详情（meta、文件列表、单文件 diff）；顶部一个「Changes」虚拟行汇总未提交变更。
- 分页续取；搜索只过滤列表不改布局（避免行号漂移）。

### 终端

- 真 PTY（`subprocess.spawnTerminal`），多标签，cwd = 工作区根，可拖高/收起。
- 切视图、切标签都不杀进程；关闭标签才终止；浏览器刷新后自动对账回收孤儿终端。
- 输入回显 120 ms 轮询；输出过大时明确提示「输出已截断」，不假装完整。

## 明确不做

- 不做 LSP / 补全 / 重构 / 调试器。
- 不做网络类 git（push/pull/fetch/clone）——本期默认关闭，P2 再评估。
- 不做扩展宿主、多根工作区、iframe 嵌入；不做跨窗口拖 tab、任意深度分栏（封顶 4 组）。
- 不注册任何模型工具：这个插件不参与对话，AI 不会自己来敲。

## 安全边界（摘要）

- **Host 路径边界**：文件、包脚本 cwd 与仓库路径都在 Host 侧校验；Git/watch 以所选仓库建立请求上下文。工作区无信任状态或信任门禁。
- **Git 调用硬化**：读写都使用 `--no-optional-locks`、关闭 fsmonitor / pager / helper / 外部 diff / 自定义 SSH，hooks 指向插件空目录，`GIT_TERMINAL_PROMPT=0`。终端里的 Git 使用用户自己的配置。
- **不改你的仓库配置**：不写 `.git/config`、不动 `safe.directory`、不自动 `git init`、不自动 stash/reset。
- **不管理凭据**：不读 Git 凭据文件，不提供密码输入或存储；本地 Git 错误显示有限命令与 stderr 摘要，详见安全文档的实际处理范围。
- 完整威胁模型见 `docs/security.md`。

## 开发

```bash
pnpm --dir packages/dsh-workspace-ide run build   # 产出 lib/（需提交，禁止手改）
pnpm build                                        # 仓库全量构建
```

本地试跑用本 profile 已装的**插件调试沙箱**能力（`plugin_dev` 工具：`bind` 绑定本包目录 → `launch` 起隔离实例 → `status` 看输出），不污染当前 profile。

> 测试纪律：是否跑测试、浏览器验证、截图由用户决定，未批准不跑。默认交付 = 实现符合需求 + `pnpm build` 通过。
