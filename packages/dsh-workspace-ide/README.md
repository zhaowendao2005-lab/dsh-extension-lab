# 文件工作台（Workspace IDE）

DSH 里的「小号 VS Code」：一个全局面板，只做三件事——**源代码管理（含提交图谱）+ 高性能文件查看编辑 + 真终端**。根目录就是你的工作区目录，不掺任何模型对话。

> **状态：设计与文档阶段。** 代码尚未开始（`lib/` 为空），本文描述的是已定稿的目标形态与边界。
> 计划与任务拆解见 `plan/全方案.md`、`docs/milestones.md`。

## 入口

侧栏底部图标「文件工作台」→ 在全局面板区打开（与「对话」平级，随时切回）。
面板不绑定会话：根目录优先用上次打开的工作区，否则取最近活跃会话的 `cwd`，也可用面板内的「打开文件夹」显式选择。

## 三个视图

### 资源管理器

- 工作区文件树，懒加载、虚拟滚动，万级目录不卡。
- 单击选中、双击打开；行内新建/重命名/删除/刷新；右键菜单。
- 打开即编辑：语法高亮、查找替换、折叠、多标签、脏标记、`Cmd/Ctrl+S` 保存。
- 大文件分级降级（256 KB / 2 MB / 10 MB / 20 MB 四档），20 MB 以上只读。
- 全局搜索（优先自带 ripgrep，缺失时降级纯 JS），结果按文件分组、点击跳行。

### 源代码管理

- 变更四组：**已暂存 / 未暂存 / 未跟踪 / 冲突**，同一文件可同时在两组（与 git 真实语义一致）。
- 逐文件：看 diff、暂存、取消暂存、丢弃（需确认）；分区级「全部暂存/取消」。
- 提交框：多行、`Cmd/Ctrl+Enter` 提交、空消息禁用；P1 支持 hunk/行级暂存与 amend。
- 分支：显示当前分支、上游、ahead/behind，一键切换；不干净时拒绝并提示 stash。
- 刷新：操作后立即刷新 + 面板可见时轮询 + 窗口聚焦刷新；超大仓库自动降级为手动刷新。

### 提交图谱

- SourceGit 风格多泳道图，固定行高虚拟滚动，5 万条提交可流畅滚动（布局在 Host 计算，客户端只画可视区间）。
- 每行：泳道连线 + 提交圆点 + refs 徽章（HEAD/branch/remote/tag）+ subject + 短 hash + 作者 + 相对时间。
- 点选看提交详情（meta、文件列表、单文件 diff）；顶部一个「Changes」虚拟行汇总未提交变更。
- 分页续取；搜索只过滤列表不改布局（避免行号漂移）。

### 终端

- 真 PTY（`subprocess.spawnTerminal`），多标签，cwd = 工作区根，可拖高/收起。
- 切视图、切标签都不杀进程；关闭标签才终止；浏览器刷新后自动对账回收孤儿终端。
- 输入回显 120 ms 轮询；输出过大时明确提示「输出已截断」，不假装完整。

## 明确不做

- 不做 LSP / 补全 / 重构 / 调试器。
- 不做网络类 git（push/pull/fetch/clone）——本期默认关闭，P2 再评估。
- 不做扩展宿主、多根工作区、iframe 嵌入。
- 不注册任何模型工具：这个插件不参与对话，AI 不会自己来敲。

## 安全边界（摘要）

- **工作区信任门禁**：未信任目录只读（可浏览、可看 diff），保存/暂存/提交/开终端需显式信任。
- **只读 git 命令硬化**：`--no-optional-locks` + 关 `core.fsmonitor`/`hooksPath`/`credential.helper`/`diff.external`/`core.sshCommand`，`GIT_TERMINAL_PROMPT=0`（这类配置键能在"打开文件夹"时执行任意命令）。
- **不改你的仓库配置**：不写 `.git/config`、不动 `safe.directory`、不自动 `git init`、不自动 stash/reset。
- **不碰凭据**：完全不读 `~/.git-credentials`，错误信息脱敏后才会显示。
- 完整威胁模型见 `docs/security.md`。

## 开发

```bash
pnpm --dir packages/dsh-workspace-ide run build   # 产出 lib/（需提交，禁止手改）
pnpm build                                        # 仓库全量构建
```

本地试跑用本 profile 已装的**插件调试沙箱**能力（`plugin_dev` 工具：`bind` 绑定本包目录 → `launch` 起隔离实例 → `status` 看输出），不污染当前 profile。

> 测试纪律：是否跑测试、浏览器验证、截图由用户决定，未批准不跑。默认交付 = 实现符合需求 + `pnpm build` 通过。
