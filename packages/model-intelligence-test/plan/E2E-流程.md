# 模型智能测试 · playwright-cli 端到端流程

目标环境：开发沙箱 `http://127.0.0.1:53039/`（带 token 的完整地址从 plugin_dev 状态里取，不要写进文档）。
所有定位都用无障碍名称（role + name），不用快照里的 `eNN` 引用，因为它们每次快照都会变。

## 0. 约定与准备

```bash
PW="playwright-cli -s=mit-e2e"
URL='http://127.0.0.1:53039/?token=<从 plugin_dev status 复制>'

$PW open "$URL"
$PW resize 1600 1000
$PW console            # 每个阶段结束都看一眼，期望 0 error
```

通用小工具（下面反复用）：

```bash
# 点击：role + name
click() { $PW click "getByRole('$1', { name: '$2' })"; }
# 断言页面出现某段文字（找不到会报错退出）
see()   { $PW run-code "async page => { await page.getByText('$1').first().waitFor({ timeout: ${2:-15000} }); }"; }
```

打开插件面板：

```bash
click button 'Open right sidebar'
$PW click "getByText('模型智能测试').first()"
click button 'Fullscreen'
see '测试记录'
```

测试模型：只用便宜模型 `a6api-other / deepseek-v4.1-flash-1017`（DSH 来源）和中转站上的一个 deepseek-v4.1-flash 渠道（中转来源）。

## 3. 中转站列表（P2）

进入「中转站来源适配」页签。

| 步骤 | 操作 | 期望 |
|---|---|---|
| 3.1 | `see '快照就绪' 60000` | 状态行「N 条渠道 · 快照就绪」，N 为一万多 |
| 3.2 | 点「提供商」，在搜索框输入 `ds` | 列表第一项是 DeepSeek（别名 ds→deepseek） |
| 3.3 | 勾 DeepSeek，再输入 `goog` 勾 Google | 两个标签按宽度换行显示；菜单保持打开；渠道数变少 |
| 3.4 | 点「模型」，输入 `v41fl` | `deepseek-v4.1-flash` 排在前面（子序列模糊匹配） |
| 3.5 | 勾 `deepseek-v4.1-flash`，`$PW press Escape` | 菜单关闭；表格只剩该模型的行 |
| 3.6 | 再开「提供商」，取消 Google | 模型筛选保留（DeepSeek 下的模型不被清掉） |
| 3.7 | 保真 → 选「保真」 | 只剩带保真标记的行（可能为 0，属正常） |
| 3.8 | 保真 → 选「直连」 | 可能为空，见「已知问题 3」；然后切回「全部」 |
| 3.9 | 排序 → 价格从低到高 / 从高到低 | 价格列首行单调变化 |
| 3.10 | 排序 → 成功率优先 / 延迟优先 | 成功率降序 / TTFT 升序 |
| 3.11 | 点「列（13）」，勾选「渠道倍率」「接口」等未显示列，再取消一列 | 表头同步增减，按钮数字变化 |
| 3.12 | 列宽拖拽（见下方脚本） | 模型列宽度变大 |
| 3.13 | 清空筛选后滚动到底（见下方脚本） | 渲染行数始终几十行，`translateY` 变大（虚拟滚动） |

```bash
# 3.12 拖拽列宽
$PW run-code "async page => {
  const h = page.getByRole('columnheader', { name: '模型' }).first();
  const b = await h.boundingBox();
  await page.mouse.move(b.x + b.width - 2, b.y + b.height / 2);
  await page.mouse.down(); await page.mouse.move(b.x + b.width + 80, b.y + b.height / 2, { steps: 8 }); await page.mouse.up();
  return (await h.boundingBox()).width;
}"

# 3.13 虚拟滚动
$PW run-code "async page => {
  const body = page.locator('.mit-relay-body, [role=table] [class*=viewport]').first();
  await body.evaluate(el => el.scrollTop = 200000);
  await page.waitForTimeout(300);
  return await page.locator('[role=row]').count();
}"
```

## 不在本流程内的项

- 几万行真实压力：虚拟滚动只验证机制（3.13），不做帧率测量。
- a6api 限流 / 封禁路径：会影响账号，不主动触发。
- 运行时重启（7.4）需要在 plugin_dev 里手动操作，脚本不自动化。

## 已知问题（这次走查时发现，尚未修复）

1. 设置页「API 适配站点」首次打开不会自动读取凭据状态，显示「未知」，要先点「刷新」。
2. 提供商 / 模型菜单里的搜索框，无障碍名称是计数（如 `19`），不是「搜索」；脚本里请用 `getByPlaceholder('模糊搜索')` 定位。
3. 「直连」筛选匿名数据里没有对应字段，大概率为空。
4. 文案过时：功能中心卡片写「当前会话 N 条记录」（记录已是全局）；中转站侧栏与抽屉底部仍写「匿名只读 / 本版本不提供登录操作」。
5. 价格旁的实时倍率单位未与官方页面核对。
