# 自定义测试设计文档

本目录是自定义测试模块的设计材料，当前只描述需求和架构，不表示功能已经实现。

- [需求文档](./requirements.md)：目标、入口、创建向导、监控、沙箱、预设和验收标准。
- [架构草案](./architecture.md)：Host/Client 分层、任务模型、调度器、权限、Remote 和分阶段实施。
- [a6api 专项设计](./a6api-design.md)：a6api 双入口、单向网页发令、Host 执行适配器、固定/解固定和账单边界。
- [交互原型](./prototype.html)：单文件 HTML 原型，用演示数据走通「新建 → 监控 → 详情 → 打开输出」的界面流程，只用于评审交互与视觉，不发请求、不执行沙箱。直接双击用浏览器打开即可。
- [迭代计划 2026-11-18](./iteration-2026-11-18.md)：继续会话白名单缺陷、步骤（轨迹）视图、输入/输出价格与渠道 24h 缓存率列、全屏面板的端口研究与实施方案，以及上一轮排序/红绿判定/并发派生的结论。

## 当前决策

1. 普通 DSH 与 a6api 使用同一个自定义任务模型和监控面板。
2. 两个入口都只负责选择目标；执行、沙箱、会话和文件均由 Host 管理。
3. a6api 网页仍是一次性发令器，不参与自定义任务执行，也不承载账户凭据。
4. 每个模型一个独立运行单元和沙箱；默认拒绝网络、工作区、凭据和跨模型访问。
5. “龙猫测试”首版只声明 HTML 输出，目标文件为沙箱内的 `output/totoro.html`。
6. 待确认的 DSH 沙箱、会话和文件预览契约集中记录在架构草案中；现有 Mock 功能不计入本模块交付。

现有 a6api 接入和账单口径见 [当前实现说明](../../docs/a6api.md)，不在本目录重复安排实施。
