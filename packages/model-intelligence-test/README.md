# 模型智能测试

普通指纹测试从 DSH 的真实模型目录选择模型；**a6api 专项指纹测试只能从官网油猴脚本提交选择进入**。两者共用官方 `lmfpd-sdk@0.2.0` 三题挑战、真实流式采样、指纹分析、测试记录和错误诊断。自定义 Agent 任务仍明确标注 Mock。

## a6api 专项：谁做什么

| 角色 | 职责 |
| --- | --- |
| a6api 网页 + 油猴脚本 | 发令器：勾选渠道、勾选测试令牌，把清单 POST 给 Host。**读完即走，不参与执行。** |
| DSH Host | 用账户访问令牌直连 a6api：固定渠道 → 取测试 key → 三题采样 → 解除固定。**不经过浏览器，不需要网页在线。** |

没有配对通道、没有轮询确认、没有回传：网页那一侧只有一个 HTTP POST。

## 第一次连接

1. **填账户访问令牌**：a6api → 个人设置 → 生成「系统访问令牌」，连同个人页里的数字用户 ID 一起填进 DSH 右栏「模型智能测试 → 功能中心 → a6api 接入」，点「保存并验证」。验证通过后 Host 会记住它（只回显掩码）。
2. **一键连接网页**：同一张卡里点「一键连接 a6api 页面」。油猴脚本读到 URL 里的接入配置就自动保存并把它从地址栏抹掉，之后不再需要手填。
3. **装油猴脚本**：Tampermonkey 新建脚本，用随包的 `integration/a6api-userscript.user.js` 完整替换内容（版本 3.0.0）。关闭旧版，刷新 a6api 页面。

> 安全边界：导入口令只存在 Host 与油猴存储里。没有它，任何网页都能往 Host 投递伪造清单（而清单会影响花钱的测试），所以这一步不能省。

## 每次测试的操作

1. 在 a6api 模型市场表格里勾选渠道（新增的「测试渠道」列，跨分页保留）。
2. 在令牌管理页勾选专用**测试令牌**（新增「测试令牌」列）。选择按 **站点 origin + a6api 账号 ID** 存 localStorage，只存 ID 与名称，账号切换不串用；脚本不读 API Key 列、不调取密钥接口。
3. 回到市场点「发送到 DSH 测试」，DSH 收到后自动打开专项创建页。
4. 在专项页勾选要当并发槽的测试令牌（1–8 个），确认清单，点「创建并开始」。

## 并发槽怎么跑

例如 20 个待测项、4 个测试令牌：

- 4 个槽位各领一个待测项，**一个令牌同一时刻只固定一个渠道**。
- 每项：`固定到该渠道（关智能兜底）` → 读回 `route_effective` → 用该令牌的 key 向 a6api 发 3 条共享挑战 → 全部流清理完 → `解除固定` → 立刻领下一项。
- 不等其他槽位整批结束；最终 20 次固定 + 20 次解除固定 + 60 个采样请求。
- 固定未生效（`route_effective:false`）时**不发送任何采样请求**：否则会把别的渠道的回答记到这个渠道名下，数据就是假的。
- 解除固定失败时任务停止并提示去 a6api 手工处理，不会带着错误状态继续跑。

为什么不用 `sk-<key>-<渠道ID>` 后缀：那是站点的广场自助测试通道，受「每账号 5 次/分钟、每渠道 20 次/分钟」限制，一撞限就是 429。固定渠道 + 普通 key 走的是正常调用口径。

## 断线、取消与恢复

- 网页关掉、断网都不影响已在跑的测试：执行全在 Host。
- 取消：停止领取新项，向在途请求传取消信号；**三条流清理完且解除固定确认前，该令牌不会复用**。
- 同一测试令牌跨任务共享身份锁；中断后重启 Host 不会留下半固定状态（固定前后都有补偿记录）。
- 不新增自动推理重试；保留「重试失败项」和「再次请求」。

## 指纹结论与指标

每次生成 3 条共享数字挑战，SDK 校验并分析。`scored` 只在 `reference_calibrated` 时显示参考库内闭集概率；`partial` 只显示 RAW 排序分数；`unscorable` 不评分；`not_model` 是行为检测结论，不是身份认定。最高候选不是模型真实身份概率，也不是智力排名。

响应走 Host 自己的 SSE 解析后交给 DSH 官方 `AssistantStreamAccumulator` / `BlockAssembler` 组装；缺失 Token、TTFT 或生成时长显示 `—`，不估算费用。错误保留 Host 脱敏后的来源、code、HTTP status、原始信息与堆栈。只收到完整 block、没有 delta 时，不伪造首 Token 时间。

参考库由 SDK 下载并验证，缓存 `$DSH_HOME/cache/model-intelligence-test/lmfpd-data.bin`，无可用参考库时明确失败，不回退 Mock。请求超时 30–1800 秒，默认 180 秒；单回答最多 24,000 字符。专项槽位数由所选测试令牌数决定，所有推理仍受运行时 18 条在途请求池约束。

## 构建与验证

在本包目录运行 `pnpm build`，包含 TypeScript、静态分层约束、Host/Client 打包和 scoped CSS；`lib/` 均由构建生成。`test/a6-orchestration.test.mjs` 用注入的固定/流钩子验证调度不变量（20 项 / 4 令牌补位、取消时令牌不提前复用、固定失效零请求、key 不可用零请求、导入口令鉴权），不访问真实模型、不改 a6api 配置。

UI 检查与真实采样分别报告：构建与本地检查成功不代表油猴已安装、真实供应商账单链路已实测。更新插件和油猴后才会使用新代码；没有安装就不声称正在运行的 DSH 已更新。
