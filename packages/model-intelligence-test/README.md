# 模型智能程度测试

右栏入口：**模型智能测试**。指纹测试已接入真实 DSH 模型调用与官方 [lm-detector](https://github.com/Ikaleio/lm-detector) / `lmfpd-sdk@0.2.0`。自定义任务仍为独立 Mock 演示，不伪装为真实 Agent 执行。

## 指纹流程

1. 从插件当前所在 DSH runtime 的真实模型目录选择供应商/模型。
2. 每条测试生成一组 **3 个共享挑战**；每题要求凭直觉输出 292–332 个 1–355 整数。所有所选模型使用同一组题目；每模型发送 3 次真实请求，可能产生供应商费用。
3. Host 通过公开 `llm.stream` 获取回答与 usage；不经过 SDK 的 API-key 请求功能，也不把供应商凭据传到浏览器。请求沿用当前适配器默认参数，不附加交付约束、工具或 Agent 对话历史。
4. SDK 解析、校验并分析回答，显示真实候选排名、样本诊断和参考库版本。

- `scored`：完整有效样本的排名；仅 `reference_calibrated` 才展示库内校准概率。
- `partial`：只有部分有效样本，展示原始排序分数，不造出置信概率。
- `unscorable`：有效样本不足，不能评分。
- `not_model`：数列特征未通过 SDK 检查，不展示排名；这是行为检测结论，不是身份认定。

最高候选代表**参考库中最相似的行为模式**，不是“真实模型身份概率”，更不是智力排名。库外模型仍可能匹配库内某个候选；低置信或异常样本需谨慎解释。

## 参考库与运行边界

使用官方默认数据源 `https://lm.ikale.io/data/` 和 `https://cdn.jsdmirror.com/npm/lmfpd-data@latest/`。SDK 负责库/检测器配对校验、下载和磁盘缓存，缓存位置为 `$DSH_HOME/cache/model-intelligence-test/lmfpd-data.bin`。缓存检查 TTL 为 1 小时，Host 每 10 分钟重新取得检测器快照；过期缓存由 SDK 后台刷新，新测试随后采用新版，已有任务固定原版本。更新失败继续用可验证的旧缓存；无可用缓存则明确报错，**不回退 Mock**。SDK 不兼容的新数据格式需要升级依赖，不自动执行代码更新。

- 单任务最多 64 个模型；模型并发槽位 1–6（默认 6），每个模型的三条挑战始终同时发出，因此默认 6 槽即 18 路并发请求。整个插件最多 18 个同时进行的采样请求、4 个进行中的测试；超出槽位或全局请求池的模型显示为排队。
- 模型并发与单请求最大时长（30–1800 秒，默认 180 秒）可在记录的「配置」面板中实时调整：降低并发或时长不会打断已开始的请求（新值只影响之后发起的请求），提高时长会延长进行中的请求。
- 回答最多保留 24,000 字符，超限标为截断。无有效回答不编造候选。
- 失败样本可在表格「操作」列按模型重试：只重发该模型的失败样本，保留其已完成样本并重新分析；已取消的测试不能重试。
- 采样失败时「采样信息」会附带 Host 侧脱敏后的诊断：错误来源、`code`、HTTP `status`、供应商原始信息与堆栈，展开即可查看，用于区分认证失败、限流、模型不存在或适配器异常；密钥类文本在离开 Host 前已被替换为 `[redacted]`。
- 完成任务保留最多 1 小时，并在新任务创建时按总记录上限 16 清理；不是持久化任务服务。
- 关闭内部页签不会取消；显式取消会中止未结束的请求。删除/清空/卸载会尝试取消任务。浏览器强制关闭、进程崩溃或断网不能保证送达取消命令，Host 超时仍生效；刷新后不恢复内存记录。
- 轮询暂时失败只显示连接错误，不能据此宣称后台执行失败。

## 指标

真实输入/输出 Token 使用 Host 的 `usage`，缺失显示 `—`；指纹费用未接入定价，不生成模拟费用。TTFT 是请求发起至首个可观察文本或推理 delta（不是 SDK 的网络首字节）；生成时长从首个到最后一个可观察 delta，端到端时长含等待及收尾。跨样本按相同有数据样本累加分子与分母，排除队列和分析。单个分块无法测得生成时长时不造速率。

## 界面与其他数据

- 全宽可关闭页签、记录侧栏；进度视图显示全部运行，结果视图显示已结束运行。模型详情替换内容区页面，以面包屑返回。
- 分组多选、完整方形标签、文字/拼音/首字母搜索；毛玻璃菜单支持外部点击和 Escape 关闭。
- 可选表格列、键盘/拖动列宽、固定右侧结果和操作列。
- 自定义任务的轮次、指标、费用和 HTML/SVG 成果仍明确标注 Mock，不启动服务或 Agent 沙箱。只有内置样例在受限 iframe 中执行绘图脚本。
- 预设按浏览器 origin 保存，不是账号同步；陈旧写入会报错但 localStorage 无跨窗口原子锁。记录、草稿、页签和表格状态按 DSH session 在内存中保存。
- 中文优先 UI；管理器元数据提供中英文。

## 构建与接入

Node.js >=22.19.0，pnpm 12.15.0。在包目录运行 `pnpm install`、`pnpm build`。构建包含 TypeScript、静态架构约束、Host/Client/scoped Tailwind CSS 和 sourcemap；`lib/` 为生成产物，禁止手改。React 由 DSH ModuleLoader 提供。依赖生命周期审批不自动放行。

Host 公开 owner-only `catalog`、`fingerprintStart`、`fingerprintConfigure`、`fingerprintRetry`、`fingerprintStatus`、`fingerprintCancel`，Client 经 Typert Remote 调用。在开发沙箱内读的是沙箱 runtime 的模型，不读沙箱选择文件或外层 Host 目录，也不修改宿主配置。

架构见 `ARCHITECTURE.md`，本包规则见 `AGENTS.md`。没有修改仓库根构建脚本或市场索引。浏览器验证只能在用户授权范围内执行。
